## 🚀 Як встановити

Відкрий Claude Code, новий чат, встав промт:

```
Встанови мені скіл з репозиторію https://github.com/JulyLay/hunt-ladder.git так, щоб він був доступний у будь-якому чаті назавжди:
1. Зклонуй репозиторій у ~/.claude/skills/hunt-ladder (якщо папки ~/.claude/skills немає — створи).
2. Видали з неї папку .git.
3. Перевір, що є файл ~/.claude/skills/hunt-ladder/SKILL.md.
4. Зроби все сам і коротко підтверди, що скіл встановлено.
```

Або командою в терміналі:

```bash
git clone https://github.com/JulyLay/hunt-ladder.git ~/.claude/skills/hunt-ladder && rm -rf ~/.claude/skills/hunt-ladder/.git
```

Далі просто опиши задачу в чаті або виклич `/hunt-ladder`.
